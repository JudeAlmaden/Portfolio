# Justine Jude D. Almaden | Portfolio

A modern, interactive portfolio website showcasing projects, skills, and professional experience in web development.

![Portfolio Preview](./images/hero.png)

## 🌟 Features

- **Modern Design**: Clean, responsive UI with smooth animations and transitions
- **Interactive Project Showcase**: Bento-grid style project display with 3D hover effects
- **Skills Section**: Visual representation of technical expertise with interactive cards
- **Contact Section**: Easy-to-use contact information with copy-to-clipboard functionality
- **Responsive**: Optimized for desktop, tablet, and mobile devices
- **Performance**: Built with React and optimized bundle for fast loading

## 🛠️ Tech Stack

### Frontend
- **React** - UI library
- **Vite** - Build tool and bundler
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library (custom implementation)

### Icons & Fonts
- **Font Awesome** - Icon library
- **Devicon** - Technology icons
- **Google Fonts** - Outfit & Inter font families

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/JudeAlmaden/Portfolio.git
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview production build:
```bash
npm run preview
```

## 🎨 Customization

### Colors
The portfolio uses a violet/indigo color scheme defined in the CSS. Modify the gradient classes and custom properties to change the theme.

### Content
Update the following in the bundled JavaScript:
- Personal information (name, email, phone)
- Project details (title, description, images, links)
- Skills list
- Social media links

### Images
Replace images in the `images/` directory with your own project screenshots.
